# Changelog

## v1.0.1（2026-11-22，家具包裹不再丢失，单件配方也能入队）

- **修复**：队列制作的家具包裹不再丢失，完成后自动拆到玄关（玄关满转抽屉/落地）
- **修复**：只能制作 1 件的配方也显示「加入队列」按钮

## v1.0.0（2026-11-21，工作台制作队列：后台自动制作，成品直进抽屉）

- **新增**：工作台可把配方任务加入队列，关闭界面后继续后台制作
- **新增**：入队即锁料——整单材料一次性锁进工作台抽屉，取消时材料留抽屉
- **新增**：成品自动进工作台抽屉，满则掉落地面；家具包裹走官方原路送玄关
- **新增**：队列面板查看进度/取消任务；精力不足自动暂停，恢复后续跑
- **新增**：前台制作与队列并行互不影响，前台动用被锁材料时会提示
- **优化**：后台制作全程不弹窗、不暂停游戏、不干扰前台操作
- **优化**：配置项精简——ModCenter 详情页只保留启用/停用，不再有调试项

### 升级注意
- 超过单件用量的大堆材料（如 50 个一叠的木头）需先手动拆堆再入队
- 每件开工时扣精力（官方同源）；取消制作中那一件已扣精力不退
